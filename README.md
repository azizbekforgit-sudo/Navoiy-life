# Bandla

Navoiyda ish, xodim va to‘yxona — bitta joyda. Работа, панель предпринимателя и тойханы в одном приложении для Навои.

Сейчас это кликабельный прототип интерфейса: данные хранятся в браузере (localStorage), сервера нет. Вход, SMS, MyID, ответы тойхан и кандидатов, оплата — имитируются.

```bash
npm install
```

```bash
npm run dev
```

- `src/store.ts` — данные, демо-наполнение, все действия
- `src/screens/` — экраны: Landing, Onboarding, Ish, Toylar, Panel, Profil
- `src/styles.css` — дизайн-токены и компоненты
- `NOTES.md` — выжимка прежних документов Navoiy Life
